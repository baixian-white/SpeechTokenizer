# 项目转移内容部署说明

这个目录用于复制到其他 Windows 机器，目标是运行两用户通信 demo 和三用户中心路由通信 demo。

## 包含内容

- `speechtokenizer/`: 本项目的 SpeechTokenizer 源码包。
- `speechtokenizer_now/speechtokenizer/两用户通信demo/`: 两用户通信 demo、模型文件、密钥文件和完整依赖列表。
- `speechtokenizer_now/speechtokenizer/三用户中心路由通信demo/`: 三用户中心路由 demo、`environment.yml` 和使用说明。
- `Log/spt_base/`: 本地训练模型的推理文件，只包含 `config.json` 和 `SpeechTokenizer_best_dev.pt`。
- `samples/`: wav 测试音频，用于绕开麦克风做链路验证。
- `README.md`、`setup.py`、`LICENSE`: 本地安装和项目说明需要的根文件。

## 环境创建

在目标机器安装 Miniconda 后，进入三用户 demo 目录：

```powershell
cd "项目转移内容\speechtokenizer_now\speechtokenizer\三用户中心路由通信demo"
conda env create -f environment.yml
conda activate st_audio_py310
python -m sounddevice
```

如果目标机器已经存在同名环境：

```powershell
conda env update -f environment.yml --prune
```

## 局域网测试注意

其他机器连接路由时，`--router_ip` 要填写运行 Router 的机器局域网 IP，不能写 `127.0.0.1`。

Router 机器如果同时作为 A 用户端，也需要保留完整项目内容，因为客户端需要加载模型并执行 SpeechTokenizer 编解码。

## 模型切换

三用户 demo 默认加载 bundle 内自带的本地训练模型（即论文 SCIT-Speech-LCA v2 权重，sha256=`af60223…`）：

```text
Log\spt_base\config.json
Log\spt_base\SpeechTokenizer_best_dev.pt
```

无需额外参数即用此模型。如需改用其它模型，启动每个客户端时同时传入：

```powershell
--config_path "<config.json 路径>" --ckpt_path "<对应 ckpt 路径>"
```

同一次通信实验中，A/B/C 三个客户端必须使用同一套模型和同一个 `--rvq_layers`，否则接收端解码会不匹配。
