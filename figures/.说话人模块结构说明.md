## 10. 模块 7：说话人分类网络的详细结构

### 10.1 网络组成与数据接口

说话人分类网络包含两条特征提取分支、一个门控融合模块和一个主分类头。Token 分支处理接收端的 RVQ 索引序列，音频分支处理相同时间区间的重建语音。两路特征分别压缩为整段语音的 256 维向量，融合后输出 110 个身份类别评分。

```text
接收 RVQ 索引 → RVQ Token Encoder → 256 维 Token Embedding ─┐
                                                         ├→ 门控融合 → 256 维 → 110 类分类头
重建语音 → 冻结 ECAPA-TDNN → 192 维 → 线性投影 → 256 维 ───┘
```

| 图中名称 | 对应网络结构 | 输入 | 输出 | 说话人训练阶段状态 |
|---|---|---|---|---|
| Trainable RVQ Token Encoder | 分层嵌入、跨层平均、4 个时序残差块、注意力统计池化、线性投影 | RVQ 索引及有效位置掩码 | 256 维向量 | 可训练 |
| Frozen ECAPA-TDNN | TDNN、3 个 SE-Res2Net 块、多层特征聚合、通道相关注意力统计池化、输出映射 | 80 维声学帧特征 | 192 维向量 | 冻结 |
| Trainable Projection | 带偏置线性层，随后 L2 归一化 | 192 维 ECAPA 向量 | 256 维向量 | 线性层可训练 |
| Learned Gate g | 门控计算、两路特征投影、逐元素加权、LayerNorm 和 L2 归一化 | 两个 256 维向量 | 256 维融合向量 | 可训练 |
| Speaker Classifier | 归一化角度分类头，训练时采用 AAM-Softmax | 256 维融合向量 | 110 个类别评分 | 可训练 |

下文统一使用 B 表示批大小，\(T_z\) 表示 RVQ 时间帧数，\(T_a\) 表示声学特征帧数。二者帧移不同；时间对齐指来自同一语音区间，而不是帧数相等。对于 3 秒语音，\(T_z\) 名义约为 150，\(T_a\) 约为 300，精确帧数与边界处理有关。

### 10.2 Trainable RVQ Token Encoder

#### 10.2.1 分层索引嵌入

输入索引按 \([B,3,T_z]\) 组织。三层各有一张独立嵌入表，每张表包含 1025 个条目，每个条目为 128 维。编号 0–1023 对应实际 RVQ 码字，编号 1024 仅为本地填充标记 PAD，不增加通信码本大小。

同一数值编号在不同层查询不同的嵌入表。每层还具有一个可学习的 128 维层身份向量 \(p_\ell\)。在时间位置 t，嵌入为：

\[
v_{\ell,t}=E_\ell[i_\ell[t]]+p_\ell.
\]

通过有效层掩码 \(m_\ell\) 对层间表示求平均：

\[
v_t=\frac{\sum_{\ell=1}^{3}m_\ell v_{\ell,t}}
{\max(1,\sum_{\ell=1}^{3}m_\ell)}.
\]

本结构采用跨层平均，不采用三层拼接。结果由带偏置线性层从 128 维投影为 256 维，形成 \([B,256,T_z]\) 的时序特征。

#### 10.2.2 时序残差块

随后连接 4 个时序残差块。每个块保持 256 通道和时间长度不变，核长为 3，膨胀率依次为 1、2、4、8。

| 块内顺序 | 运算 | 参数或维度 |
|---|---|---|
| 1 | 逐通道一维卷积 | 256→256，k=3，groups=256 |
| 2 | GELU | 256 通道 |
| 3 | 逐点一维卷积 | 256→256，k=1 |
| 4 | GroupNorm | 1 组，256 通道 |
| 5 | 与块输入相加 | 256 通道 |
| 6 | GELU 与有效帧掩码 | 保留真实帧，屏蔽填充位置 |

四个卷积块本身的最大时间感受野为 \(1+2(1+2+4+8)=31\) 帧，在 50 Hz 下约为 0.62 秒。后续池化聚合整段输入，因此最终嵌入的上下文范围不限于这 31 帧。

#### 10.2.3 注意力统计池化与输出

池化权重网络为：核长 1 卷积 256→128、Tanh、核长 1 卷积 128→1，再沿有效时间位置执行 Softmax，得到 \(\alpha_t\)。此 Token 分支每个时间位置有一个注意力权重，权重由各通道共同使用。

\[
\mu=\sum_t\alpha_t h_t,\qquad
\sigma=\sqrt{\max\left(\sum_t\alpha_t(h_t-\mu)^2,\epsilon\right)}.
\]

256 维均值与 256 维标准差拼接为 512 维；带偏置线性层 512→256 后进行 L2 归一化，得到 \(e_t\in\mathbb R^{256}\)。该输出对应整段语音，不再保留时间轴。

### 10.3 Frozen ECAPA-TDNN 的详细结构

#### 10.3.1 模型名称与基本配置

ECAPA-TDNN 是强调通道注意力、传播与聚合的时延神经网络。此处使用在 VoxCeleb 上预训练的 1024 通道版本，其输出为 192 维说话人嵌入。

| 配置项 | 本模型采用的值 |
|---|---|
| 声学输入维度 | 80 |
| 主干通道 | 1024、1024、1024、1024 |
| 多层聚合输出通道 | 3072 |
| 主干时间卷积核 | 5、3、3、3 |
| 对应膨胀率 | 1、2、3、4 |
| Res2Net 通道分组数 | 8，每组 128 通道 |
| SE 中间通道 | 128 |
| 注意力网络中间通道 | 128 |
| 激活与特征归一化 | ReLU、BatchNorm |
| 最终输出 | 192 维 |

ECAPA 内部的通道注意力与图中两路融合的 Learned Gate 是不同模块：前者在音频主干内调节通道，后者在主干外融合 Token 与音频嵌入。

#### 10.3.2 声学前端

重建波形采用 16 kHz 采样率，计算 80 维滤波器组声学特征。前端使用 25 ms 窗长、10 ms 帧移，对应 400 点窗长和 160 点帧移，FFT 长度为 400。随后对每条语音执行逐特征维的时间均值归一化，不执行标准差归一化。

前端输出形状为 \([B,T_a,80]\)，进入时序卷积时转换为 \([B,80,T_a]\)。这些声学帧不是模块 2 的 RVQ 帧：ECAPA 前端帧率约为 100 Hz，而 RVQ 帧率为 50 Hz。

#### 10.3.3 主干逐阶段结构

```text
80 维声学特征
→ 初始 TDNN：80 → 1024，k=5，d=1
→ SE-Res2Net 块 1：1024 → 1024，k=3，d=2
→ SE-Res2Net 块 2：1024 → 1024，k=3，d=3
→ SE-Res2Net 块 3：1024 → 1024，k=3，d=4
→ 拼接三个 SE-Res2Net 块的输出：1024×3 = 3072
→ 聚合 TDNN：3072 → 3072，k=1，d=1
→ 通道相关注意力统计池化：3072 → 6144
→ BatchNorm：6144
→ 输出映射：6144 → 192
```

| 阶段 | 核心运算 | 输出形状 |
|---|---|---|
| 初始 TDNN | Conv1D → ReLU → BatchNorm | \([B,1024,T_a]\) |
| SE-Res2Net 1 | 多尺度时间处理、通道注意力、残差相加 | \([B,1024,T_a]\) |
| SE-Res2Net 2 | 同结构，时间卷积膨胀率变为 3 | \([B,1024,T_a]\) |
| SE-Res2Net 3 | 同结构，时间卷积膨胀率变为 4 | \([B,1024,T_a]\) |
| 多层拼接 | 拼接上述三个块的输出 | \([B,3072,T_a]\) |
| 聚合 TDNN | 1×1 时序卷积 → ReLU → BatchNorm | \([B,3072,T_a]\) |
| 统计池化 | 每通道加权均值与标准差拼接 | \([B,6144,1]\) |
| 池化后归一化 | BatchNorm | \([B,6144,1]\) |
| 输出映射 | 核长 1 的卷积，等价于单位置线性映射 | \([B,192,1]\) |

主干卷积保持时间长度，时间轴在统计池化处才被汇聚。拼接的是三个 SE-Res2Net 输出，初始 TDNN 输出不作为第四项加入该拼接，因此是 3072 而非 4096 通道。

#### 10.3.4 SE-Res2Net 块内部结构

每个块包含以下顺序：

```text
输入 u：1024 通道
→ TDNN 1×1：1024 → 1024，ReLU，BatchNorm
→ Res2Net：8 组，每组 128 通道，层级式时间卷积
→ TDNN 1×1：1024 → 1024，ReLU，BatchNorm
→ SE 通道注意力：1024 → 128 → 1024
→ 与块输入 u 相加
```

三个块的输入输出通道一致，外层旁路为恒等连接。该残差结构与解码器中的可学习投影旁路不同。

Res2Net 将 1024 通道分为 8 组 \(x_1,\ldots,x_8\)。第一组直接通过，后续各组按层级组合：

\[
y_1=x_1,\qquad y_2=K_2(x_2),\qquad
y_j=K_j(x_j+y_{j-1}),\quad j=3,\ldots,8.
\]

最后将八组结果拼接回 1024 通道。\(K_j\) 是 128→128 的核长 3 时间卷积及其 ReLU、BatchNorm；同一块中的膨胀率一致，三个大块分别取 2、3、4。层级连接使不同组累计经历不同深度的时间变换。

#### 10.3.5 SE 通道注意力

SE 先沿时间轴对每个通道求平均，得到 1024 维摘要，再执行 1024→128 映射、ReLU、128→1024 映射与 Sigmoid：

\[
s=\frac1{T_a}\sum_t u_t,\qquad
a=\sigma\left(W_2\operatorname{ReLU}(W_1s+b_1)+b_2\right).
\]

得到的 \(a\in(0,1)^{1024}\) 沿时间广播，与原特征逐通道相乘。它在该语音片段内对不同特征通道赋予不同权重，不改变时间长度或通道数。

#### 10.3.6 多层聚合与通道相关注意力池化

设三个块的输出为 \(h^{(1)},h^{(2)},h^{(3)}\)。聚合模块计算：

\[
h_{\rm agg}=\operatorname{TDNN}_{1\times1}
([h^{(1)};h^{(2)};h^{(3)}]).
\]

池化的注意力网络同时读取每帧 3072 维特征、整段均值和整段标准差，组成 9216 通道的上下文描述。其层序为：

```text
特征、全局均值、全局标准差拼接：9216 通道
→ TDNN 1×1：9216 → 128，ReLU，BatchNorm
→ Tanh
→ 1×1 卷积：128 → 3072
→ 沿时间 Softmax
```

这里得到的是每个通道各自的时间权重 \(\alpha_{c,t}\)，与 Token 分支“各通道共享一套时间权重”的池化不同。每个通道分别求加权均值和标准差：

\[
\mu_c=\sum_t\alpha_{c,t}h_{c,t},\qquad
\sigma_c=\sqrt{\max\left(\sum_t\alpha_{c,t}(h_{c,t}-\mu_c)^2,\epsilon\right)}.
\]

将 3072 维均值和 3072 维标准差拼接为 6144 维，经过 BatchNorm 和 6144→192 输出映射，形成整段音频嵌入。该 192 维输出进入图中的 Trainable Projection。

#### 10.3.7 本任务使用的 ECAPA 边界

本任务仅使用 ECAPA 的声学前端、输入均值归一化和嵌入主干。预训练模型配套的 7205 类原始分类头不用于此处 110 类任务；配套的全局嵌入均值归一化也不在本任务这条特征调用路径中。

说话人训练时，ECAPA 主干参数冻结，BatchNorm 使用固定的推理统计量。音频分支后面的线性投影单独训练。冻结状态不改变上述网络拓扑，只改变参数是否更新。

### 10.4 Trainable Projection：音频特征投影

#### 10.4.1 结构与计算

该模块不是另一套深层网络，而是一个带偏置的全连接层，将 ECAPA 输出的 192 维向量映射为 256 维，再执行 L2 归一化：

\[
v_a=W_ph_a+b_p,\qquad
e_a=\frac{v_a}{\max(\|v_a\|_2,\epsilon)}.
\]

其中 \(h_a\in\mathbb R^{192}\)、\(W_p\in\mathbb R^{256\times192}\)、\(b_p\in\mathbb R^{256}\)。这一层包含 \(256\times192+256=49408\) 个可训练参数。

```text
ECAPA embedding [B,192]
→ Linear 192→256，带偏置
→ L2 normalization
→ Audio speaker embedding [B,256]
```

该位置没有额外的 ReLU、GELU、BatchNorm 或 Dropout。L2 归一化没有可训练参数。当前音频输入适配步骤为恒等映射，不额外增加一个前置学习层。

#### 10.4.2 功能与训练范围

投影层将冻结的 ECAPA 特征重新组合为当前身份任务需要的方向，同时使音频和 Token 输出维度一致。由 192 扩展到 256 并不生成新的原始观测信息，而是学习到新的坐标表示。

分类训练更新 \(W_p,b_p\)，但不更新 ECAPA 主干。投影输出既送入门控融合，也可送入音频辅助分类头。图中的 Trainable 指的是该线性映射的权重可学习。

### 10.5 Learned Gate g：门控融合模块

#### 10.5.1 输入与内部组成

输入为 Token 嵌入 \(e_t\in\mathbb R^{256}\) 和投影后的音频嵌入 \(e_a\in\mathbb R^{256}\)。模块包含三条计算支路和一个输出归一化步骤：

| 部分 | 运算 | 输入维度 | 输出维度 |
|---|---|---:|---:|
| 门控支路 | 拼接两路嵌入 | 256 + 256 | 512 |
| 门控支路 | 带偏置线性层 + Sigmoid | 512 | 256 |
| Token 变换支路 | 带偏置线性层 | 256 | 256 |
| Audio 变换支路 | 带偏置线性层 | 256 | 256 |
| 加权合并 | 逐元素乘法与相加 | 两个 256 维向量 | 256 |
| 输出处理 | LayerNorm + L2 归一化 | 256 | 256 |

音频的这个 256→256 变换与前述 Trainable Projection 的 192→256 变换是两个不同层，参数不共享。

#### 10.5.2 门控生成与加权公式

\[
g=\sigma(W_g[e_t;e_a]+b_g),\qquad g\in(0,1)^{256},
\]

\[
v_t=W_te_t+b_t,\qquad v_a=W_ae_a+b_a,
\]

\[
u=g\odot v_t+(1-g)\odot v_a,
\qquad
e_f=\operatorname{L2Norm}(\operatorname{LayerNorm}(u)).
\]

g 是根据当前输入动态计算的 256 维向量。它不是固定常数，不是单个标量，也不直接表示身份概率。对于第 j 个维度，\(u_j=g_jv_{t,j}+(1-g_j)v_{a,j}\)。两个权重逐维相加为 1，但之后还存在 LayerNorm 与 L2 归一化，因此最终嵌入不仅是未经处理的加权平均。

#### 10.5.3 可训练参数与归一化

门控线性层包含 131328 个参数，两路 256→256 投影各包含 65792 个参数，LayerNorm 具有 256 个缩放参数和 256 个偏移参数。因此该融合模块共包含 263424 个可训练参数。

LayerNorm 在每条融合向量的 256 个维度上进行归一化，并学习缩放与偏移；L2 归一化随后使向量具有单位长度，便于角度分类。两种归一化的计算目标不同，不能互相替代。

### 10.6 Speaker Classifier：110 类角度分类头

#### 10.6.1 层结构

该模块接收 256 维融合嵌入，输出 110 维类别评分。它不包含多层隐藏 MLP，而是一个可学习的类别权重矩阵及角度评分运算：

\[
W\in\mathbb R^{110\times256}.
\]

每一行对应一个说话人类别的权重向量。该矩阵没有偏置，共有 \(110\times256=28160\) 个可训练参数。输入嵌入和类别权重按向量分别进行 L2 归一化后计算内积。

```text
Fusion embedding [B,256]
→ 与归一化类别权重 [110,256] 计算余弦相似度
→ 训练时对真值类别施加角度间隔
→ 乘评分尺度 30
→ 类别评分 [B,110]
→ 推理时 argmax
→ 类别编号映射为 Speaker ID
```

#### 10.6.2 AAM-Softmax 训练形式

令 \(\theta_c\) 为嵌入与第 c 类权重之间的夹角。训练时采用角度间隔 m=0.2、尺度 s=30：

\[
\ell_c=
\begin{cases}
s\cos(\theta_c+m),&c=y,\\
s\cos\theta_c,&c\ne y.
\end{cases}
\]

真实类别 y 的角度被增加固定间隔，再用交叉熵优化。类别之间需要形成更明确的角度区分，才能降低该训练目标。

推理时没有真值标签，也不添加真值角度间隔，而是统一计算 \(\ell_c=s\cos\theta_c\)。最终取最大评分的类别。Softmax 可将评分转换为类别分布，但 argmax 不要求先计算 Softmax。

#### 10.6.3 主分类头与辅助分类头

训练网络保留三个独立分类头：Token 头、Audio 头和 Fusion 头。三者结构相同，均为 256→110 的角度分类头，但权重互不共享。主输出来自 Fusion 头。

\[
\mathcal L_{\rm spk}=\operatorname{CE}(\ell_f,y)
+\lambda_{\rm aux}\operatorname{CE}(\ell_t,y)
+\lambda_{\rm aux}\operatorname{CE}(\ell_a,y).
\]

辅助目标为两条特征提取分支分别提供身份监督，主融合头学习结合两者。三个头合计具有 84480 个类别权重参数；如果只统计图中主分类头，则是 28160 个。

### 10.7 参数更新范围与任务定义

| 组件 | 说话人分类训练时是否更新 |
|---|---|
| 语音编码器、RVQ 码本、语音解码器 | 否 |
| ECAPA-TDNN 嵌入主干 | 否 |
| Token Encoder | 是 |
| 音频 192→256 投影 | 是 |
| 门控生成层与两路融合投影 | 是 |
| 融合 LayerNorm | 是 |
| 三个身份分类头 | 是 |

本模块针对固定 110 个身份进行闭集分类。训练、验证、测试采用不同语句组，但身份集合保持一致。所用语句组划分为每人 80 个训练组、15 个验证组和 15 个测试组，训练裁剪长度为 3 秒；同组录音的不同麦克风版本不跨集合。

网络预测的是已定义类别中的一个身份，不负责未知身份拒识、说话人分离或新用户自动登记。模块 6 的 GAN 判别器判断真实与生成语音，模块 7 的分类头判断身份，二者的标签和训练目标不同。

说话人分类在接收端运行，不额外传输 192/256 维嵌入。预测身份也不反向参与语音波形重建。
