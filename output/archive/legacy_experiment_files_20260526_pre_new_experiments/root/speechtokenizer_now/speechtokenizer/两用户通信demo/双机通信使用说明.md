# 双机通信使用说明

本文档用于两台电脑之间的实时语音通信（双机互通）。

## 1. 使用范围

- 接收端脚本：`demo_recv_B_double.py`
- 发送端脚本：`demo_send_A_double.py`
- 模型配置：`model_hub/speechtokenizer_hubert_avg/config.json`
- 模型权重：`model_hub/speechtokenizer_hubert_avg/SpeechTokenizer.pt`

## 2. 运行前准备

1. 进入目录：

```powershell
cd H:\H-CODE\speechtokenizer\speechtokenizer_now\speechtokenizer\两用户通信demo
```

2. 安装依赖（首次）：

```powershell
pip install -r requirements.txt
```

3. 查看音频设备 ID（可选）：

```powershell
python ..\测试文件夹\check_device.py
```

4. 查看本机 IP：

```powershell
ipconfig
```

## 3. 双机启动顺序

必须先在两台机器都启动接收端，再启动发送端。

### 第一步：两台机器都启动接收端（Listener）

主机 1：

```powershell
python demo_recv_B_double.py --listen_ip 0.0.0.0 --listen_port 12346 --spk_device <主机1扬声器ID> --device cpu --monitor --config_path model_hub/speechtokenizer_hubert_avg/config.json --ckpt_path model_hub/speechtokenizer_hubert_avg/SpeechTokenizer.pt
```

主机 2：

```powershell
python demo_recv_B_double.py --listen_ip 0.0.0.0 --listen_port 12346 --spk_device <主机2扬声器ID> --device cpu --monitor --config_path model_hub/speechtokenizer_hubert_avg/config.json --ckpt_path model_hub/speechtokenizer_hubert_avg/SpeechTokenizer.pt
```

### 第二步：两台机器都启动发送端（Sender）

主机 1（连接到主机 2 的 IP）：

```powershell
python demo_send_A_double.py --peer_ip <主机2IP> --peer_port 12346 --mic_device <主机1麦克风ID> --device cpu --mic_sr 16000 --monitor --config_path model_hub/speechtokenizer_hubert_avg/config.json --ckpt_path model_hub/speechtokenizer_hubert_avg/SpeechTokenizer.pt
```

主机 2（连接到主机 1 的 IP）：

```powershell
python demo_send_A_double.py --peer_ip <主机1IP> --peer_port 12346 --mic_device <主机2麦克风ID> --device cpu --mic_sr 16000 --monitor --config_path model_hub/speechtokenizer_hubert_avg/config.json --ckpt_path model_hub/speechtokenizer_hubert_avg/SpeechTokenizer.pt
```

## 5. 参数总览

说明：

- 监视参数是 `--monitor`，不是 `--minitor`。
- 标记为“必填”的参数必须给出。

### 5.1 `demo_send_A_double.py` 参数

| 参数 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--config_path` | 是 | 无 | 模型配置文件路径（`config.json`）。 |
| `--ckpt_path` | 是 | 无 | 模型权重路径（`SpeechTokenizer.pt`）。 |
| `--device` | 否 | `cuda` | 推理设备：`cuda` 或 `cpu`。 |
| `--mic_device` | 否 | `None` | 麦克风设备 ID；`None` 表示系统默认输入设备。 |
| `--mic_sr` | 否 | `0.0` | 麦克风采样率；`0` 表示使用设备默认采样率。 |
| `--frame_seconds` | 否 | `0.02` | 麦克风回调帧长（秒）。 |
| `--chunk_seconds` | 否 | `0.25` | 编码发送分块时长（秒）。 |
| `--rvq_layers` | 否 | `0` | 发送的 RVQ 层数；`0` 表示全部层。 |
| `--monitor` | 否 | 关闭 | 打开实时监视输出（如 RMS）。 |
| `--peer_port` | 否 | `12346` | 对端接收端口。 |
| `--peer_ip` | 是 | 无 | 对端主机 IP。 |

### 5.2 `demo_recv_B_double.py` 参数

| 参数 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--config_path` | 是 | 无 | 模型配置文件路径（`config.json`）。 |
| `--ckpt_path` | 是 | 无 | 模型权重路径（`SpeechTokenizer.pt`）。 |
| `--device` | 否 | `cuda` | 推理设备：`cuda` 或 `cpu`。 |
| `--listen_port` | 否 | `12346` | 本机监听端口。 |
| `--spk_device` | 否 | `None` | 扬声器设备 ID；`None` 表示系统默认输出设备。 |
| `--out_sr` | 否 | `0` | 输出采样率；`0` 表示自动使用设备默认（失败则回退模型采样率）。 |
| `--monitor` | 否 | 关闭 | 打开播放/缓冲监视输出。 |
| `--frame_out_seconds` | 否 | `0.02` | 播放回调帧长（秒）。 |
| `--target_lat` | 否 | `0.25` | 目标播放延迟（秒）。 |
| `--max_lat` | 否 | `0.80` | 最大允许延迟（秒），超出后会裁剪旧音频。 |
| `--drop_when_over` | 否 | 关闭 | 缓冲过载时直接丢包，减少解码压力。 |
| `--listen_ip` | 否 | `0.0.0.0` | 监听网卡地址，`0.0.0.0` 表示监听所有网卡。 |

## 6. 说明

- `--peer_port` 要和对端 `--listen_port` 一致。
- 两台不同机器都监听 `12346` 不冲突，因为 IP 不同。
- 停止程序：`Ctrl + C`。
