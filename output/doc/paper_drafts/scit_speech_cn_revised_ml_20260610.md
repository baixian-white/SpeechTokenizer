# SCIT-Speech：基于共享 RVQ 码本索引传输的极低码率语音通信

> 中文修订稿（常规 ML 论文体例，2026-06-10）。本稿基于 `output/experiments/` 已完成的 exp1–exp11、`output/doc/实验记录.md` 与当前论文素材整理；不新增未完成实验结论。与 2026-06-09 稿相比，本稿降低了 8 样本 baseline 的结论强度，重写了 LCA 因子化消融解释，并单独讨论 test-clean 高码率 ASR 退化模式。

## 摘要

我们提出 SCIT-Speech，一个面向 500–1500 bps 极低码率语音通信的离散索引传输系统。SCIT-Speech 将分层残差向量量化（RVQ）码本与解码器作为发送端和接收端预共享的系统知识，运行时信道仅传输前 `L` 层 RVQ 索引。在每层码本含 1 024 个码字、潜在帧率 50 Hz、3 层 RVQ 的当前实例下，每增加一层索引约增加 500 bps，形成 500/1000/1500 bps 三个工作点。

围绕该接口，我们给出三项设计：第一，受约束的教师引导分阶段 NAS 搜索协议，并由该协议得到一个相对手工 SEANet 编码器在参数量、MACs、实时率上分别下降 86.9%、89.5%、55.1% 的发送端编码器候选；第二，结合波形重建、多尺度 mel 频谱、对抗、码本承诺与 HuBERT 语义蒸馏的 SCIT-Speech-Base 训练；第三，由随机操作点采样、强信道扰动模拟和 mel 域无扰动—扰动一致性损失组成的低负载信道感知适配（LCA）微调。

在 LibriSpeech `test-clean` (n=2620) 与 `test-other` (n=2939) 全量评估上，LCA 在全部 6 个无扰动单元上一致降低 mel-L1、提高 STOI；在全部 12 个索引置 0/替换单元与全部 12 个丢包/突发丢失单元上，mel-L1 与 STOI 全部改善，PESQ 多数条件改善而 SI-SNR 表现混合。在 Whisper base.en ASR 上，`test-other_300` 全部 L 层与 `test-other_100` 全部扰动条件下 WER 一致下降；`test-clean_300` 在 L=1/L=3 改善而 L=2 持平略升，`test-clean_100` 在最低操作点 L=1 的高度随机替换条件下 WER 明显下降，但 L=2/L=3 多个扰动单元下 LCA 略差。消融显示，HuBERT 语义蒸馏显著改善验证集 mel 重建与各 L 层 ASR 可懂度；LCA 三组件因子化（V0–V4，n=256 × 12 单元配对评估）显示信道扰动模拟、随机操作点采样、一致性损失三者均给出统计显著的边际贡献。

本文不主张在常规码率上超过 Opus 或 DAC；当前 500–1500 bps 区间的同码率 codec 对照仅在 8 条固定样本上完成，应作为定性快照而非统计性结论。本文成果限定在 500–1500 bps 共享码本索引传输的工作区间。

**关键词**：极低码率语音通信；共享码本；RVQ 索引传输；信道感知训练；NAS 语音编码器；语义蒸馏

## 1 引言

未来通信系统在卫星窄带回传、应急中继、嵌入式语音前端、多用户边缘网关等场景下，单路语音可分配的实际负载常远低于常规宽带 codec 的工作区间。在 500–1500 bps 这一极低码率区间，系统目标不再是逼近无损波形，而是在受控负载下保持可懂度、自然度与下游可用性。

近年来神经音频压缩与语音离散表征工作（SoundStream、EnCodec、DAC、SpeechTokenizer、WavTokenizer）[1-5] 已在低码率语音重建上取得进展，但其系统化评估通常集中在 6 kbps 及以上，且通常把码本与解码器视作模型内部组件。语音语义通信工作（DeepSC-S、DeepSC-ST 与近期结合大型语音模型的语义通信工作）[11-15] 将联合信源—信道编码（JSCC）思想引入语音传输，但运行时实际占用信道的对象与码率核算往往依赖具体调制或连续信道符号定义。

本文研究一个更窄的问题：**如果发送端与接收端预先共享 RVQ 码本与解码器，运行时信道仅传输前 `L` 层离散索引，能否在 500–1500 bps 区间得到可用的语音质量与扰动鲁棒性。** 我们把这一系统称为 SCIT-Speech（Shared-Codebook Index Transmission Speech）。在该接口下，码率核算可写成“层数 × 潜在帧率 × 每索引比特数”的封闭形式；`L` 成为单一通信旋钮；通信扰动可被建模为对离散索引序列的随机置 0、随机替换、丢包与突发丢失。

本文贡献如下：

1. 提出 SCIT-Speech 共享码本索引传输接口，把 RVQ 码本与解码器作为预共享系统知识、运行时信道仅传输离散索引；在每层 1 024 码字、潜在帧率 50 Hz、3 层 RVQ 实例下给出 500/1000/1500 bps 三个可控工作点。
2. 提出受约束的教师引导分阶段 NAS 搜索协议，并由该协议得到一个相对手工 SEANet 编码器在参数量、MACs、实时率上分别下降 86.9%、89.5%、55.1% 的发送端编码器候选。
3. 提出低负载信道感知适配（LCA）训练配方，由随机操作点采样、强信道扰动模拟与一致性损失三组件组成，并通过 V0–V4 因子化消融量化每一组件的边际贡献。
4. 在 LibriSpeech `test-clean` (2620)、`test-other` (2939) 全量上完成无扰动重建、索引随机置 0/替换、丢包/突发丢失三类评估，并在 Whisper base.en 子集上给出无扰动与扰动条件下的 ASR/WER；其中 `test-clean` 高码率 ASR 上的部分退化模式在 §6.5 单独讨论。

我们不主张在所有码率与所有指标上击败既有 codec：在 6 kbps 以上 Opus、DAC 仍是更优选择；当前 500–1500 bps 区间的同码率对照仅在 8 条固定样本上完成，应作为定性快照而非统计性结论。本文的有效区间为 500–1500 bps。

## 2 相关工作

**神经音频 codec 与离散语音表征**。SoundStream [1]、EnCodec [2]、DAC [3] 用端到端编码器—解码器结合 RVQ 实现可变码率神经音频压缩；SpeechTokenizer [4]、WavTokenizer [5]、Mimi [6] 进一步探索语音离散表征在语言模型与流式低码率下的统一接口。RepCodec [7] 把 codec 重构对象从波形改为 HuBERT/data2vec 等自监督表示，强调离散表征的语义保真度。本文沿用 RVQ 与多层结构，但将码本与解码器重新定位为预共享系统知识，并把评估操作带下移到 500–1500 bps。

**语义特征蒸馏与语义—声学分层**。HuBERT [8] 及其离散单元被广泛用作 codec 的语义监督信号。SpeechTokenizer [4] 用 HuBERT 蒸馏把语义信息集中到第 1 层 RVQ；AudioLM [9] 把语义表征与声学表征显式分层并以语言模型串联两级；VALL-E [10] 直接把 EnCodec [2] 的离散码作为语言模型建模目标。本文沿用“HuBERT 蒸馏 + 多层 RVQ”的语义—声学分层思想，但目的不是为下游语言模型提供输入符号，而是为低 L 工作点保留可懂度。

**语音语义通信与离散接口下的联合信源—信道编码**。DeepSC-S [11]、DeepSC-ST [13] 与 Qin 等综述 [12] 把语义通信思想引入语音传输，多采用高维连续联合信源—信道编码映射 [16] 把语音直接映到信道符号；近期 LargeSC [14] 引入大型语音基础模型作为收发端先验，Glaris [15] 把抗丢包恢复机制建在语义通信框架内。本文采取互补路径：在共享 RVQ 码本下把信道传输对象明确化为离散索引，码率成为层数、潜在帧率与码本大小的封闭形式，通信扰动也相应建模为索引层面的随机置 0、随机替换、丢包与突发丢失。

**丢包扰动下的神经语音重建**。神经丢包隐藏（PLC）在波形或频谱域估计丢失帧。Valin 等 [17] 用混合生成—预测模型实时填补丢失内容，tPLCnet [18] 用短上下文时域网络做实时丢包隐藏。这类工作通常把“丢包”视为接收端波形缺失，在解码后做单独修复。本文则将扰动直接作用在传输的 RVQ 索引序列上，并通过同一解码器在扰动索引下产生稳定重建；这与额外丢包隐藏模块的路线互补。

**语音 / 音频编码器 NAS**。DARTS [19]、ProxylessNAS [20] 已把硬件感知搜索范式带入工业级模型；LightSpeech [21] 将 NAS 用于轻量化 TTS 声学模型。这些工作或针对图像分类与通用 CNN，或针对 TTS 声学模型，搜索目标与“低码率语音通信发送端编码器”的接口契约不同。本文的搜索约束更窄：固定潜在帧率、潜在维度与 RVQ 接口，只搜索发送端编码器，并把参数量、MACs、实时率三个发送端硬件指标纳入搜索。

## 3 方法

![图 1：SCIT-Speech 系统总览](../scit_speech_method_cn_draft_20260609论文素材/框架图.png)

**图 1**：SCIT-Speech 系统总览。RVQ 码本与解码器在发送端与接收端预先离线部署，运行时不进入信道；信道仅传输前 `L` 层离散索引。图示为 `L = 3` 情况，后两层索引在较低操作点下不传输。信道扰动（索引随机置 0、随机替换、丢包、突发丢失）作用于离散索引序列。HuBERT 教师分支仅在训练阶段参与蒸馏，推理时移除。

### 3.1 共享码本索引传输

设输入语音 `x(t)`，发送端编码器 `E_θ` 输出连续表示 `Z = E_θ(x) ∈ R^{T_q × d}`。`Z` 经分层 RVQ 量化为 `M` 层离散索引 `I = {i_{m,t}}`，发送端与接收端预共享码本 `C* = {C_1*, ..., C_M*}`、解码器 `D` 与系统配置；运行时信道只传输前 `L` 层索引 `I_L = I_{1:L,:}`，接收端经 `x̂ = D(C*(I_L))` 重建。

当前系统实例取 `M = 3`、`K = 1024`、采样率 16 kHz、编码器总下采样率 320，因此潜在帧率 `f_q = 50` Hz。每个索引需 `⌈log₂ K⌉ = 10` 比特表示，仅算离散索引、不计分组化与协议开销时的紧凑封装上界为

```
R(L) = L · f_q · ⌈log₂ K⌉ = 500 L  bps,   L ∈ {1, 2, 3}.
```

该实例对应 500 / 1000 / 1500 bps 三个工作点。分组化、文件头、UDP/TCP 报头等工程开销不在该核算范围内。

**符号汇总**。下文沿用以下符号：`x` 输入波形；`x̂` 重建波形；`E_θ` 编码器；`D` 解码器；`C*` 预共享 RVQ 码本族；`I` 全层索引张量；`I_{1:L}` 前 `L` 层截断索引；`Ĩ_{1:L}` 经信道扰动后的索引；`M` RVQ 总层数；`L` 运行时传输层数；`K` 单层码本大小；`f_q` 潜在帧率；`φ_s` 第 s 个尺度的对数 mel 算子；`h^{HuBERT}` HuBERT 教师特征。

### 3.2 SCIT-Speech-Base 训练

设输入波形 `x`、模型重建 `x̂ = D(C*(I))`，把“编码器 + RVQ + 解码器”整体记作生成器 `G`。Base 训练在 LibriSpeech train-clean-100 上以联合目标优化生成器 `G` 与判别器集合 `D̂`：

```
L_full = L_mel(x, x̂) + λ_recon · L_recon(x, x̂)
       + L_adv(D̂, x̂) + L_feat(D̂, x, x̂)
       + λ_q · L_commit + λ_distill · L_distill(z, h^{HuBERT}(x))
```

其中：`L_recon` 为波形 L1；`L_mel` 为多尺度对数 mel 频谱 L1；`L_adv` 与 `L_feat` 为 HiFi-GAN 风格的最小二乘对抗损失与判别器中间特征匹配损失；`L_commit` 为 RVQ 码本承诺损失；`L_distill` 将编码器输出与 HuBERT 教师特征对齐，鼓励低层索引保留内容相关信息。HuBERT 教师仅在训练阶段参与，推理时移除。具体 STFT 尺度、各项权重与训练超参见 §4.5。

### 3.3 SCIT-Speech-LCA：低负载信道感知适配

在 SCIT-Speech-Base 之上做端到端微调，把训练目标拆成两个分支：全深度分支沿用 Base 的 `L_full`，通信分支显式建模低层索引截断与信道扰动。总损失为

```
L_LCA = λ_full · L_full + λ_comm · L_comm.
```

通信分支由三部分组成。

**随机操作点采样**。每训练步在 `L ∈ {1, 2, 3}` 中均匀采样一个操作点，发送端对一批样本编码得到全 3 层索引，截断到前 `L` 层得到 `I_{1:L}`。采样粒度为训练步而非样本，即同一批内所有样本共用同一个 `L`，以避免同一步内不同 `L` 的判别器输入布局、对抗损失与特征匹配损失互相干扰；样本级随机化留作后续实验。

**信道扰动模拟**。在无扰动、中度/高度随机置 0、中度/高度随机替换五种条件中均匀采样。随机置 0 在索引序列中独立抹除若干位置，并用同一层前一帧原始索引替代；随机替换则把被选中的索引替换为同码本中的随机有效索引。两类扰动独立施加，得到 `Ĩ_{1:L}`：

```
x̂_clean = D(C*(I_{1:L})),     x̂_pert = D(C*(Ĩ_{1:L})).
```

通信分支重建项为

```
L_comm_recon = L_mel(x, x̂_pert) + λ_recon · L_recon(x, x̂_pert).
```

**无扰动—扰动一致性损失**。在非无扰动条件下，额外对同一截断索引的无扰动解码输出与扰动解码输出施加 mel 域一致性约束：

```
L_consistency = Σ_s w_s · ‖φ_s(x̂_clean) − φ_s(x̂_pert)‖_1.
```

该设计意图是让解码器在索引被置 0、替换、丢包或突发丢失时仍产生与无扰动索引一致的频谱结构。`L_consistency` 需要与 `L_comm_recon` 配合使用：前者约束扰动不变性，后者仍把扰动输出拉向真值。本文未单独验证“仅 consistency”是否会产生复制偏差；训练动力学诊断列入补充实验文档。

**梯度路径**。通信分支中的截断索引与扰动索引不携带梯度，通信分支的梯度仅沿解码器回传；编码器与量化器的梯度来自全深度分支。该设计使 LCA 主要训练“解码器如何在低 L 与扰动索引下稳定重建”，而不是直接改变发送端编码器或码本。

### 3.4 受约束 NAS 发送端编码器

发送端计算成本对低负载语音通信同样重要。我们用教师引导的分阶段 NAS 在固定接口契约（潜在维度、总下采样、潜在帧率、RVQ 层数与码本大小固定）下搜索编码器架构，码本与解码器不参与搜索。

搜索空间围绕 SEANet 编码器展开，包含下采样步长、基础通道数、残差块压缩比、瓶颈 LSTM 层数、激活函数、各层卷积算子以及是否使用通道注意力。搜索分四阶段进行：第一阶段进行架构剖面与资源门控；第二阶段用冻结教师做短程蒸馏代理；第三阶段延长代理训练并加入 RVQ 兼容性诊断；第四阶段在少数候选上做多目标 Pareto 排序，综合教师潜在空间损失、量化后特征误差、代理重建质量、参数量、MACs 与实时率选择最终候选。

整个 NAS 代理阶段使用冻结教师路径评估，代理质量只用于相对排序，不直接构成 SCIT-Speech 的最终质量指标；最终质量由 §3.2 的完整训练衡量。当前论文只报告选定候选的效率指标，Pareto 邻居与代理质量表列入补充实验文档。

## 4 实验设置

### 4.1 数据与评估层级

| 层级 | 数据 | 用途 | 实验编号 |
|---|---|---|---|
| 训练 | LibriSpeech train-clean-100 | Base 与 LCA 训练 | exp2 / exp3 |
| 同码率对比 | 固定 8 条 train-clean-100 样本 | 同码率对比传统与神经 codec | exp4 |
| 评估子集 | test-clean 100 / test-other 100 | 评估管线验证 | exp6 |
| 全量无扰动 | test-clean 2620 / test-other 2939 | 无扰动条件下泛化 | exp7 |
| 全量索引扰动 | test-clean 2620 / test-other 2939 | 中度/高度索引随机置 0 与随机替换 | exp8 |
| 全量丢包/突发 | test-clean 2620 / test-other 2939 | 1%/3%/5% 丢包，2/5/10 帧突发丢失 | exp9 |

固定接口：采样率 16 kHz、总下采样 320、潜在帧率 50 Hz、3 层 RVQ、每层码本 1 024 码字，传输层数 1/2/3 对应 500/1000/1500 bps。

### 4.2 同码率对比基线（exp4）

固定 8 条 train-clean-100 同码率对比包括：SCIT-Speech-Base 与 LCA v2（L=1/2/3）、PCM 16 bit @ 16 kHz、Opus 6/8/12/16/24 kbps、EnCodec 1.5/3/6/12 kbps、DAC 多个 RVQ 层数档。AMR-WB 因当前 ffmpeg 构建缺编码器被迫跳过；Codec2、ViSQOL、主观 MOS 未纳入。

### 4.3 评价指标

客观指标：波形 L1、mel-L1、SI-SNR、相关系数、STOI、PESQ-WB。任务层指标：Whisper base.en 的 WER 与 CER。无损 PCM 上 Whisper 在固定 8 条样本上 WER ≈ 0.075，构成测量下界。

### 4.4 索引扰动与丢包/突发丢失

索引级扰动包含中度/高度随机置 0 与中度/高度随机替换；通信化扰动包含 1%/3%/5% 丢包与 2/5/10 帧突发丢失。正文主表只放较强档（高度索引随机置 0、高度索引随机替换、5% 丢包、10 帧突发丢失）；中等档与较弱档放附录。

### 4.5 实现细节

通用训练机制：训练数据为 LibriSpeech train-clean-100，波形片段长度 1 秒，批大小 8、梯度累积 4，Adam 优化器，余弦退火，不做学习率预热，bf16 混合精度，随机种子 42。判别器由多周期判别器、多尺度时域判别器与多尺度 STFT 判别器三组组成。

Base 训练在 §3.2 的损失配方下端到端训练 60 轮，初始学习率为 1e-4，取 dev/mel 最低值的模型权重作为 SCIT-Speech-Base，最优 dev/mel = 1.124。蒸馏权重当前取 30；早期 120 权重配置 dev/mel 明显较差，但本文未做精细 sweep。

LCA 训练在 SCIT-Speech-Base 之上加载生成器权重，判别器、优化器、学习率调度器从零重启；微调 10 轮，初始学习率为 1e-5。每 2 500 步在验证集上计算 3 个操作点 × 5 个信道条件的 `dev/comm_mel` 矩阵，取高度随机替换三档同时全局最优的模型权重作为正式 LCA 模型。

NAS 编码器效率测量在单卡 RTX 5070 Ti、批大小 1、1 秒波形输入、fp32 精度下进行，仅计编码器段（不含 RVQ 与解码器）。后续补充实验将把预热与统计次数写成固定脚本，以消除“预热是否计入均值”的歧义。

### 6.2 LCA v1 与 v2 鲁棒性对比（exp3）

LCA 训练过两个版本：v1 为弱扰动、无一致性损失；v2 为正式配方，使用更强扰动并加入一致性损失。二者差距是扰动强度、通信分支权重和一致性损失的合成效应，因此本节只作为配置级对照；严格边际贡献由 §6.3 的 V0–V4 因子化给出。

按 12 组 (L, 扰动) 单元的鲁棒性改进 = Base 退化 − LCA 退化聚合：

| 指标 | v1 均值 | v2 均值 | v1 中 LCA 更鲁棒单元数 | v2 中 LCA 更鲁棒单元数 |
|---|---:|---:|---:|---:|
| **mel-L1** | -0.0003 | **+0.0055** | 3 | **12** |
| **PESQ-WB** | -0.002 | **+0.015** | 7 | **10** |
| **STOI** | -0.0001 | **+0.0023** | 6 | **9** |
| SI-SNR | -0.018 dB | +0.051 dB | 4 | 7 |
| 相关系数 | -0.0003 | +0.0010 | 5 | 7 |
| 波形 L1 | ~0 | ~0 | 6 | 7 |

v1 几乎无鲁棒性收益；v2 在 6 个客观指标的均值上均为正。由于本节评估样本较小且配置差异不止一项，本文不在此处给出显著性结论。

### 6.3 LCA 组件因子化（exp5 V0–V4）

为定位随机操作点采样、信道扰动模拟、一致性损失三组件的独立贡献，我们训练 V0/V1/V2/V3 四个变体，并与 V4 = 正式 LCA 共同评估。评估使用统一 256 样本 train-clean-100 子集；每个变体在 12 个扰动单元（3 个 L × 4 个非无扰动条件）上按样本编号配对计算 mel 鲁棒性改进。

| 变体 | 随机操作点采样 | 信道扰动模拟 | 一致性损失 |
|---|---|---|---|
| V0 全深度无扰动对照 | 否（固定 L=3） | 仅无扰动 | 无 |
| V1 仅随机操作点采样 | 是 | 仅无扰动 | 无 |
| V2 仅信道扰动模拟 | 否（固定 L=3） | 强 | 无 |
| V3 随机操作点采样 + 信道扰动模拟 | 是 | 强 | 无 |
| V4 完整 LCA | 是 | 强 | 有 |

每个 (样本, L, 信道条件) 单元上定义 mel 鲁棒性改进 = Base 退化 − LCA 退化，正值表示 LCA 在该单元下扰动鲁棒性更强。12 单元均值与配对 95% 置信区间如下：

| 变体 | 12 单元 mel 鲁棒性改进均值 | 95% 置信区间 | 正向单元数（共 12） |
|---|---:|:---:|:---:|
| V0 | **−0.00135** | [−0.00159, −0.00112] | 2 |
| V1 | **−0.00245** | [−0.00288, −0.00201] | 6 |
| V2 | +0.00258 | [+0.00220, +0.00297] | 8 |
| V3 | +0.00494 | [+0.00459, +0.00527] | 12 |
| V4 | **+0.00742** | [+0.00704, +0.00781] | 12 |

进一步在每个 (样本, L, 信道条件) 上做配对差值，并对 12 单元 × 256 样本 = 3 072 个配对样本做配对 t 检验：

| 比较 | 池化 Δ 鲁棒性改进 | 95% 置信区间 | t 统计量 | p 值 | 显著单元数（共 12） |
|---|---:|:---:|---:|---:|:---:|
| **V3 − V1**（在 random-L 之上加入信道扰动模拟） | **+0.00739** | 待补 | 待补 | 待补 | 待补 |
| **V4 − V3**（加入一致性损失） | **+0.00248** | [+0.00203, +0.00294] | +10.6 | **7.3 × 10⁻²⁶** | 10 |
| **V3 − V2**（在信道扰动模拟之上加 random-L） | +0.00236 | [+0.00188, +0.00284] | +9.6 | **1.1 × 10⁻²¹** | 4 |
| **V2 − V1**（ChannelSim-only 与 random-L-only 的配置对比） | +0.00502 | [+0.00448, +0.00557] | +18.2 | **2.5 × 10⁻⁷⁰** | 12 |
| V4 − V0（端到端总效益） | +0.00877 | [+0.00832, +0.00923] | +37.8 | < 10⁻²⁵⁶ | 12 |

解释如下。第一，仅 random-L 不带来扰动鲁棒性（V1 仍为负）。第二，信道扰动模拟是必要成分：V2 相对 V1 显著更好，V3 相对 V1 的严格边际对比将在补充实验中补齐 CI 与 p 值。第三，random-L 在信道扰动模拟之上仍有显著增益（V3−V2 为正），并提供对 L=1/2/3 三个工作点的训练覆盖。第四，一致性损失把 12 单元均值从 +0.00494 推到 +0.00742，是完整 LCA 的关键最后一步。第五，V2−V1 并不等价于“在 random-L 上加入 ChannelSim”的纯边际效应，因为二者同时改变了 random-L 是否启用；论文采用 V3−V1 与 V4−V3 作为更干净的边际路径。

该结果仅作为发送端效率证据，不代表质量优于手工编码器。手工编码器在同条件下的完整训练对照尚未完成；NAS Pareto 邻居的代理质量表也尚未纳入正文，列入补充实验文档。

### 6.5 test-clean 高码率 ASR 退化模式

虽然 LCA 在全量 mel-L1 与 STOI 上一致改善，并在 `test-other` ASR 上稳定降低 WER，但 `test-clean` 的高码率 ASR 子集呈现不同模式：无扰动 `test-clean_300` 的 L=2 WER 略升，扰动 `test-clean_100` 的 L=2/L=3 多数单元 WER 略升。可能原因包括：第一，test-clean 在较高 L 下 Base 已接近当前 ASR 测量下界，LCA 的扰动正则可能带来轻微语音细节偏移；第二，通信分支主要训练解码器在扰动索引下稳定重建，而不直接训练编码器和码本，可能在干净、简单语音、高码率条件下牺牲少量 ASR 友好性；第三，LCA 的 checkpoint 选择以 `dev/comm_mel` 为准，而非 WER 最优。本文据此不宣称 LCA 在所有 ASR 条件下全面改善，而将结论限定为“困难语音与扰动叠加条件下收益更明显”。

## 7 局限性

1. **跨语料与跨语言未覆盖**：评估全部基于 LibriSpeech；VCTK、AISHELL、跨语言、真实通信语音未覆盖。
2. **AMR-WB 与 Codec2 缺失**：当前 ffmpeg 构建缺 AMR-WB 编码器；Codec2 与 ViSQOL 未纳入。
3. **主观 MOS 与 AB 听测缺失**：PESQ-WB、STOI、WER 不能完全替代 MOS。
4. **NAS 与手工编码器同条件质量对照未完成**：当前 NAS 结果仅作为发送端效率证据，不能证明质量优于手工编码器。
5. **NAS Pareto 代理质量未纳入正文**：选定候选的代理质量与 Pareto 邻居表尚未整理进主文，列入补充实验。
6. **码本利用率不健康**：当前主训练运行的 RVQ 码本利用率 17–27%，第 1 层死码占比较高；后续需做死码重启、k-means 初始化、利用率熵正则等专项修复。
7. **同码率 codec 对照样本量小**：exp4 仅 8 条固定样本，无置信区间；不能作为统计性 benchmark 结论。
8. **蒸馏权重未做精细 sweep**：当前只比较了无蒸馏与主配置，早期高权重配置较差，但中间权重尚未系统评估。
9. **一致性损失机制仍需动力学诊断**：本文展示了最终鲁棒性收益，但未直接展示 `dev/full_mel`、`dev/comm_mel` 与 clean/perturbed 输出距离的训练过程。
10. **分组化工程开销**：本文索引负载仅算紧凑封装上界，不含分组化、文件头、UDP/TCP 报头等工程开销；端到端延迟、抖动、抖动缓冲与多用户实时验证留作未来工作。

## 8 结论

本文提出 SCIT-Speech，一个面向 500–1500 bps 极低码率语音通信的离散索引传输系统。发送端与接收端预共享 RVQ 码本、模型参数与系统配置，运行时信道仅传输前 `L` 层离散索引；当前实例形成 500/1000/1500 bps 三个工作点。我们通过受约束 NAS 得到轻量发送端编码器候选，通过 HuBERT 蒸馏训练得到 Base，通过随机操作点采样、强信道扰动模拟与一致性损失得到 LCA。在 LibriSpeech 全量无扰动重建、索引随机置 0/替换、丢包/突发丢失评估上，LCA 在 mel-L1 与 STOI 上相对 Base 一致改善；在 Whisper base.en ASR 上，LCA 在困难集合 test-other 全部 L 层与 test-other_100 全部扰动条件下降低 WER。消融显示 HuBERT 蒸馏与 LCA 三组件均对最终结果重要，其中一致性损失是完整 LCA 中进一步提升 mel 鲁棒性的关键最后一步。后续工作将扩展到跨语料、跨语言、AMR-WB 与 Codec2、主观听测、码本利用率修复、NAS 同条件质量对照以及分组化负载与多用户实时通信验证。
