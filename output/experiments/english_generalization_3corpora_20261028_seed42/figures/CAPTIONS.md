All figures use measured results. Error bars: 95% percentile cluster bootstrap intervals, 2,000 draws. VCTK and LibriSpeech cluster by speaker; TED-LIUM by talk; FLEURS by prompt because speaker IDs are unavailable. Intervals describe evaluation sampling, not training-seed variation. Codec checkpoints are frozen. SI-SNR uses common-length truncation with no time alignment. WER is a fixed automatic-recognition probe, not a human listening score. The bitrate figure shows means only; full intervals and failure denominators are provided in the CSV tables.
