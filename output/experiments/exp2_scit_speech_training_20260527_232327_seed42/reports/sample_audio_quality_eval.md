# 样本语音质量定量评估

- 实验编号：exp2_scit_speech_training_20260527_232327_seed42
- 评估对象：`samples/fixed` 与 `samples/full_utterance` 中已经由 best-dev checkpoint 生成的语音样本。
- 评估方式：逐条比较原始语音与重建语音，计算侵入式客观指标。这里未运行 ASR，因此不包含 WER/CER。

## 结论

- L3 在两组样本上都是当前最好配置，STOI、PESQ-WB、SI-SNR 与相关系数均优于 L1/L2。
- 从 L1 到 L2 是主要提升阶段：完整句子上 Mel L1 降低约 21.2%，STOI 提升约 0.0736，PESQ-WB 提升约 0.264，SI-SNR 提升约 7.07 dB。
- 从 L2 到 L3 仍有收益，但增益变小：完整句子上 Mel L1 再降低约 5.9%，STOI 提升约 0.0257，PESQ-WB 提升约 0.180。
- 所有样本的裁剪比例均为 0，说明重建语音没有明显削波问题。
- PESQ-WB 绝对值仍偏低，说明虽然 L3 的可懂度指标已经较好，但听感质量仍有改进空间。

## 指标说明

- 波形 L1 / Mel L1：越低越好，表示重建语音与原始语音的差异更小。
- SI-SNR、相关系数、STOI、PESQ-WB：越高越好，分别反映信号保真度、波形相关性、可懂度与主观听感代理质量。
- RMS 比例 dB：重建语音相对原始语音的响度差，负值表示重建语音整体偏小。
- 裁剪比例：重建波形接近满幅削波的样本点比例。
