# Results v3 修改与核验说明

日期：2026-09-18。

## 交付范围

本版基于 Results v2 重构论证顺序，并落实作者对 NAS 和说话人识别结尾的修改要求。英文独立排版稿共 **5 页双栏**，包含 **5 个小节、2 幅图、3 张表和 3 个公式**。同时提供完整中文对照。

原主稿、已完成的 Methods、补充方法及 v2 保持不变；本版尚未合入原主稿。未新增训练、测试推理或实验结果。

## 本轮明确修改

1. 删除 NAS 小节中关于代理评分不能代表最终质量、编码器 RTF 不能代表端到端时延的限制性总结。该节现在以编码器规模降低、保持相同索引接口的结果收束。
2. 删除说话人识别小节末尾关于未完成分支消融、文本控制、短窗口及进一步身份认证任务的清单式限制讨论。该节现在以冻结表示中的身份信息保留、接收端复用及无需额外身份载荷的结果收束。
3. 将第一节组织为共享表示与学习阶段概述，串联架构选择、SCIT 联合训练、SCIT-LCA 微调及冻结后识别。
4. 将 LCA 的既有目标式引入 Results，直接连接设计理由和受扰重建结果。公式来自现有 Methods，不是新提出的训练方案。
5. 压缩重复复现说明；搜索步数、字节补齐和缓存核验等细节使用现有 Methods 或补充方法的准确引用。
6. 重新绘制三面板框架图，分别显示索引接口、连续学习阶段及接收端双分支识别。NAS 图仍由相同归档数据生成。
7. 调整双栏图表位置与末页栏平衡，保留原模板字号，不使用手动分页或额外空白扩充页数。

## 当前完整结构

1. 共享索引表示支持重建与接收端复用。
2. 保持接口的搜索降低编码器资源需求。
3. 1.5 kbit/s 编解码器改善客观重建指标。
4. 信道适应改善受扰索引的重建。
5. 冻结索引表示保留说话人信息。

论证顺序为：表示建立 → 生成成本 → 重建质量 → 扰动适应 → 下游信息复用。
